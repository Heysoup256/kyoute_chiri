# 共テ地理ナビ

大学入学共通テスト「地理総合、地理探究」対策用のインタラクティブ世界地図＆総合学習Webアプリケーションです。

## 主な機能（4ビュー構成）
- **世界地図（`地図`）**：全240カ国・地域（うち詳細86カ国・気候都市113都市）の出題重要度ヒートマップ、ケッペン13区分気候図、世界土壌図、年間降水量、農業形態、標高、宗教、言語分布、赤道常時表示・経緯線目盛り。プレート境界、大山脈・大河川、方向矢印付き海流、火山・ホットスポット、大気大循環オーバーレイ（季節移動する高圧帯・偏西風・貿易風・モンスーン・ENSO・熱帯低気圧）。
- **国別詳細パネル**：基礎統計、生活・実景写真、地名タップ連動ハイライト、電源構成や人口比較などの図表カード、他国との関係リンク、雨温図・ハイサーグラフ（気候区分位置の自動ハイライト連動）・産業三角図表・人口ピラミッド・出題履歴。
- **世界統計データブック（`統計`）**：農林水産・資源・発電・工業・人口移動の全36品目ランキング（生産 vs 輸出対比、共通テスト判別の鉄則、上位国の世界地図一括ハイライト連動）＋農業生産性・経済高齢化4象限散布図。
- **系統地理マスター図鑑（`系統`）**：地図投影法/主題図/GIS・河川/海岸/氷河/乾燥/カルスト地形＆防災・ケッペン判別フロー＆土壌成帯・ウェーバー工業立地論＆国際分業＆主要国際河川6本＆地域統合＆ウォーレス線・集落形態＆都市構造＆人口転換＆伝統住居/灌漑/宗教/語族まで全35トピック・SVG図解付き。
- **日本地理・地域調査＆地形図（`日本`）**：新旧地形図の変化パターン・等高線/縮尺計算・地域調査の解法・日本9地方データマップ。
- **横断検索・記録機能**：全240カ国・統計品目・系統用語・日本地方を一括検索できるフィルターパネル、★マーク機能。

## ローカル開発・起動手順

```bash
cd app
npm ci
npm run dev
```

ビルドと静的検証：

```bash
cd app
npm run build
npm run lint
```

## GitHub Pages デプロイ手順
1. GitHub リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択します。
2. `main` ブランチへの push 時に `.github/workflows/deploy-pages.yml` が自動実行され、`https://<username>.github.io/<repo-name>/` にデプロイされます。
