# 共テ地理ナビ

大学入学共通テスト「地理総合・地理探究」対策用のインタラクティブ世界地図＆学習Webアプリケーションです。

## 主な機能
- **世界地図＆地域主題図**：出題重要度ヒートマップ、ケッペン13区分気候図、世界土壌図、年間降水量、農業形態、標高、宗教、言語分布、赤道常時表示・経緯線・緯度経度表示
- **自然・気象オーバーレイ**：プレート境界、大山脈・大河川、方向矢印付き海流、火山・ホットスポット、世界の首都、季節移動する大気循環（高圧帯・偏西風・貿易風・モンスーン・ENSO・熱帯低気圧）
- **国別詳細パネル**：全240カ国・地域の基本統計、生活・実景写真、地名タップ連動ハイライト、特徴に応じた図表カード（発電構成・人口推移・国際比較等）、他国との関係リンク、雨温図・ハイサーグラフ・2都市グラフ比較・産業三角図表・人口ピラミッド
- **過去問連動（2015〜2026年・全22回710問）**：共通テスト「地理総合・地理探究」「地理B」およびセンター試験「地理B」の出題実績・正解データ・関連国検索に対応
- **学習ユーティリティ**：逆引き検索（非破壊枠線ハイライト）、暗記（ブラインド）モード、★マーク機能

## 過去問画像に関するご注意（著作権保護）
- 本リポジトリおよび公開 GitHub Pages 版には、著作権保護のため **共通テスト／センター試験の過去問PDF本体（`共テ地理過去問/`, `data_pipeline/raw/wayback_pdfs/`）および設問切り抜き画像（`app/public/data/clips/`）を収録していません**。
- 公開版では各設問のメタデータ・設問概要テキストのみが表示されます。ご自身のローカル環境に過去問切り抜きデータを配置した場合は自動で問題画像が表示されます。

## ローカル開発・起動手順

```bash
cd app
npm ci
npm run dev
```

ビルドと静的検証：

```bash
cd app
npm run build
npm run lint
```

## GitHub Pages デプロイ手順
1. GitHub 上でリポジトリを作成し、このローカルリポジトリの `main` ブランチを push します。
2. GitHub リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選択します。
3. `main` ブランチへの push 時に `.github/workflows/deploy-pages.yml` が自動実行され、`https://<username>.github.io/<repo-name>/` にデプロイされます。
