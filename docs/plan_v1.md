# 大学入学共通テスト「地理総合・地理探究」対策Webアプリ 全体設計書 (`plan_v1`)

- **バージョン**: v1.0
- **作成日**: 2026-11-22
- **対象科目**: 大学入学共通テスト「地理総合・地理探究」（および過去の地理Bデータを含む）
- **運用環境**: ローカル環境（PC・スマートフォンからのレスポンシブブラウザ閲覧を想定）

---

## 1. アプリケーションの目的と概要

世界中の国々の自然環境・気候・産業統計・生活文化・歴史的経緯を体系的に整理し、共通テスト過去問の出題実績と紐づけて視覚的に学習できる個人用Webアプリケーション（**共テ地理ナビ**）を構築する。

ホーム画面のインタラクティブな世界地図から国や自然地形を選択し、気候グラフ（雨温図・ハイサーグラフ）の動的描画や、該当国に関連する共通テスト過去問の切り抜き問題をその場で「見る／解く」ことができる仕組みを備える。

---

## 2. システム全体アーキテクチャ

個人学習用途・ローカル完結運用を前提とし、バックエンドサーバーや外部データベースを持たない **フロントエンド完結型（静的JSONデータベース＋ブラウザ描画）** と **Pythonデータ生成パイプライン** の2層構成を採用する。

```text
[共テ地理過去問/*.pdf] ──(Python前処理・AI抽出・切り抜き)──> [data_pipeline/raw/]
                                                                       │
                                                       (validate & build_dataset.py)
                                                                       ▼
[ブラウザ (PC / スマホ)] <──(Vite 静的配信)── [app/public/data/*.json / *.geojson / clips/*.png]
```

### 推奨技術スタック
| 領域 | 採用技術 | 選定理由 |
| :--- | :--- | :--- |
| **フロントエンド** | Vite + React + TypeScript | 高速な開発・ビルド体験と、JSONスキーマに一致した厳密な型安全性による保守性の両立。 |
| **UI / スタイリング** | Tailwind CSS + Lucide React | PC（2ペイン）・スマホ（全画面地図＋ボトムシート／モーダル）のレスポンシブUIを簡潔に実装可能。 |
| **地図描画** | MapLibre GL JS | WebGLによる高速な国境ポリゴン・複合地形レイヤー描画、データ駆動の重要度ヒートマップ切替、動的ハイライトに対応。 |
| **ベースマップ** | OpenFreeMap (Positron) | APIキー不要・無料で詳細な地図タイルを利用可能（※オフライン時は海色背景＋GeoJSONポリゴン描画へ自動フォールバック）。 |
| **グラフ描画** | Apache ECharts | 2軸複合グラフ（雨温図）および1〜12月閉ループ軌道グラフ（ハイサーグラフ）を単一ライブラリで高精度に描画可能。 |
| **スキーマ検証** | JSON Schema + Zod / Python | Python生成時とフロントエンド読込時の双方でデータ整合性を検証。 |
| **状態保存** | `localStorage` | 気になった・苦手としてマークを付けておきたい国（★マーク）のリストのみをローカル保存するシンプル設計。 |

## 3. 主要設計方針

### 3.1 地図・地形レイヤー設計
- **ベースマップ**: OpenFreeMap の `positron` ベクタースタイルを下地とし、正確な海岸線・地名・地形コンテキストを提供する。ネットワーク未接続やタイル読込失敗時は、海色背景＋Natural Earth 国境ポリゴン単体描画へ自動フォールバックする。
- **国境データ (`geo_countries_v1.geojson`)**: Natural Earth 110m Admin 0 Countries をベースに軽量化し、フランス(`FRA`)・ノルウェー(`NOR`)等で `ISO_A3` が `"-99"` になる欠損を `ISO_A3_EH` / `ADM0_A3` / `SOV_A3` で補完した正規化済み `iso3` を主キーとする。
- **重要度ヒートマップ＆地域単位の主題図レイヤー（9モード）**: 共通テスト頻出度ランク（S / A / B / C）および★マーク済み・通常地図は国境単位で着色し、**ケッペンの気候区分・年間降水量・農業の種類・標高・宗教分布・言語系統**は国境ではなく**地域単位の分布（WorldClim実測グリッド＋地域ゾーンラスタ6枚 + 地点/地域ホバー解説）**で描画。
- **自然・地形・首都・火山＆大気大循環オーバーレイ**:
  - 常設/切替レイヤー: 大山脈、大河川（20×20px拡大クリック判定）、海流、PB2002地球規模プレート境界338本、特徴的地形、重要海峡・運河、**世界の首都199都市**、**主な火山・ホットスポット26座**。
  - **気象・大気大循環オーバーレイ**: 高圧帯/低圧帯/偏西風/貿易風（1月・春秋・7月の南北季節移動）、モンスーン（夏・冬）、エルニーニョ/ラニーニャ切替、台風/ハリケーン/サイクロンを重ね表示可能。

### 3.2 重要度ランク算出方針（ハイブリッド方式）
- 手元にある直近3年分（2024〜2026年 本試・追試 計6回分）の過去問のみでは、特定年度に出題が偏り、定番重要国のランクが過小評価される可能性がある。
- そのため、`countries_base_v1.json` 側に設定できる `manualRankOverride` と、過去問抽出JSONから自動計算する出題回数・頻度スコアを組み合わせたハイブリッド方式で `rank`（S / A / B / C）を決定する。

### 3.3 レスポンシブデザイン方針（PC・スマホ両対応）
- **PC（768px以上）**: 画面左側に世界地図、右側に固定幅の国別詳細サイドパネルを配置した2ペイン構成。地図上のレイヤー切替・凡例はフローティングパネルとして常時アクセス可能。
- **スマートフォン（768px未満）**: 地図を画面いっぱいに展開し、レイヤー切替や凡例は折りたたみ可能なコンパクトメニューに格納する。国をタップすると画面下部からスライドアップするボトムシート／全画面オーバーレイ型の詳細ビューが開き、グラフや過去問モーダルも横スクロール無しで快適に操作できる。

### 3.4 過去問PDF問題単位切り抜き＆演習機能
- Phase 2 以降、`共テ地理過去問/` 配下のPDF（変更・削除は厳禁）から Python (`pymupdf`) を用いて大問・設問単位に切り抜き画像（高解像度PNG、必要に応じて切り抜きPDF）を生成し、`app/public/data/clips/` 配下に配置する。
- 国別詳細画面および各個別項目に「関連する過去問を見る／解く」ボタンを配置し、モーダル上で問題画像の拡大閲覧・4択解答・即時正誤判定・簡易解説を行えるようにする。
- Phase 1（MVP）ではUI導線とデータスキーマ・テキストベースのプロトタイプ演習機能を先行実装し、Phase 2 で実PDFの切り抜きデータを接続する。

### 3.5 データ収録方針
- **初期（Phase 1）**: 共テ頻出の主要10カ国（日本・ドイツ・アメリカ・中国・インド・ブラジル・オーストラリア・ノルウェー・チリ・エジプト）を先行整備し、全UIとグラフ・地図・演習導線を検証する。
- **Phase 2〜4**: 過去問6回分の全問解析に合わせて主要50〜60カ国へ拡充し、未登録国は地図上で「データ準備中」として表示しつつ段階的に全世界へ拡大する。

## 7. 将来の過年度過去問（Wayback Machine 等）追加手順

1. Wayback Machine 等から入手した過去問PDF・正解PDFを `共テ地理過去問/` に保存する。
2. `data_pipeline/scripts/extract_past_exams.py` の `EXAMS` リストに新規試験エントリを追記し、実行して切り抜きPNGと `data_pipeline/raw/past_exams/<examId>_v1.json` を生成する。
3. 以下のコマンドで統合データ再生成と検証を行う：
   ```powershell
   python data_pipeline/scripts/build_dataset.py
   python data_pipeline/scripts/validate_data.py
   ```
